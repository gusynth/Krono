# Segurança

Não publique bancos, backups pessoais, tokens ou passos de exploração em uma issue aberta.

Para um problema de segurança, utilize a opção de relato privado na aba **Security** do repositório quando estiver disponível. Caso não esteja, abra uma issue apenas solicitando um canal privado, sem anexar informações sensíveis.

Informe a versão do Krono, a versão do Windows, o comportamento observado e o impacto. Não execute testes de instalação ou restauração sobre seu único conjunto de dados.

O aplicativo funciona localmente e não oferece criptografia dos backups. O uso de IA durante o desenvolvimento não é uma garantia de segurança; correções precisam ser verificadas e publicadas em uma nova versão.
